# Case Template

Use this template for every live court case evaluation. Each file must be present.

## Required Files

| File | Purpose |
|---|---|
| `public-record.md` | Public facts and sources |
| `claimed-state.md` | What is being claimed |
| `required-root.md` | What roots are needed to evaluate the claim |
| `contradictions.md` | Contradictions found in the evidence |
| `rootpass-decision.md` | The RootPass decision and reasoning |
| `enforcement-simulation.md` | What would happen if the decision were enforced |
| `sources.md` | All sources used |
| `disclaimer.md` | Legal and scope disclaimer |
