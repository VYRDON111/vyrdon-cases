# Cases by Processing Room

The system operates five processing rooms. Each room handles a specific business domain. These cases demonstrate how the RootPass methodology applies within and across rooms.

## Room Case Map

|------|--------|-----------|
| [Commercial](commercial-room-case.md) | Transaction flows | Payment contradictions, settlement failures, receipt gaps |

| [Campaign](campaign-room-case.md) | Outreach | Conversion tracking gaps, audience drift, message inconsistency |
