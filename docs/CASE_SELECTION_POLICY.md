# Case Selection Policy

Cases are selected based on:
1. Public availability of source material
2. Relevance to one or more target markets
3. Presence of clear evidence chains (or documented gaps)
4. Ability to demonstrate methodology behavior (PASS, NO_PASS, or HOLD)
5. Educational value for understanding common patterns

Cases are NOT selected to prove VYRDON is right. They are selected to show how the methodology behaves.
